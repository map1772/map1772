### Что сейчас в работе

**[via-direct-api](https://github.com/map1772/via-direct-api)** — создание рекламных кампаний в Яндекс.Директе по текстовому брифу. Бриф превращается в структурированный план, человек его проверяет, после подтверждения кампания создаётся через официальный API v5. Разделение на два шага сделано специально: перед тем как что-то появится в чужом рекламном кабинете, это должен увидеть человек.

**[health-index](https://github.com/map1772/health-index)** — модель оценки цифрового присутствия локального бизнеса от 0 до 100 с разбором по категориям и HTML-отчётом для владельца. Отчёты по ней ушли тридцати компаниям.

**[triumph-reels](https://github.com/map1772/triumph-reels)** — конвейер вертикальных роликов на Remotion. Текст, тайминги и субтитры задаются данными, ролик пересобирается за минуты вместо ручного монтажа.

**[parser-2gis](https://github.com/map1772/parser-2gis)** — сбор карточек компаний из каталога 2GIS в готовую таблицу. На реальном прогоне 867 компаний по четырём городам.

**[triumph-digital](https://github.com/map1772/triumph-digital)** — сайт собственного сервиса, статика плюс серверная функция приёма заявок в Telegram.
